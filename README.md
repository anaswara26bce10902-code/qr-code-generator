#UPI Payment QR Code Generator
## DESCRIPTION
'A Lightweight Python utility that dynamically generates custom UPI payment qr codes for major Indian payment apps including **phonepe**, **paytm**, **googlepay**, simply input a UPI ID, and the scrit generates saved'.png' QR code filtersand previews them instantly.

##Features 
-**Multi_app compatibility:** Generates individual, app_ready QR codes for:
-Phonepe ('phonepe_qr.png')
-Paytm ('paytm_qr.png')
-Google pay ('google_pay_qr.png')
-**Dynamiic UPI Link Generation;** Automaticallu formats custom URIs adhering to standerd Indian NPCI UPI specsb('upi://pay?pa1).
-** AUtomatic Export:** Save high-resolution '.png' files directly to your working directory.
-**Instant Preview:** Uses Pillow (PIL) to immediately open and display generates QR codes.

**Prerequisites
Ensure you have  **python 3.x** installed  in your system.
